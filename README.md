# Liberty

Liberty is a straightforward app for tracking your assets, liabilities, and net worth, helping you stay on top of your financial health.

## Technology Stack

- React
- Vite
- Tailwind CSS
- Supabase
- Vercel

## Roadmap

- **Accessibility** – Add `title` and `alt` attributes to SVG logo.
- **Feature** – Separate assets/liabilities from `AddRecordForm`; add “Other” category; add option to mark Car or Realty as having a loan/mortgage and automatically add debt as a liability.ff
- **Feature** – Add expenses tracking with payment reminders.
- **Feature** – Add “Edit” functionality to `Record` component, reusing logic from `AddRecordForm`.
- **UI** – Sidebar integration.
- **Refactor** – Convert all components to TypeScript.
- **Refactor** – Move data fetching out of `App.jsx` into feature-specific container components and create a dedicated `services/` folder for Supabase queries to keep `App.jsx` slim and improve separation of concerns.

## About

This open-source project was built as a personal initiative to strengthen my proficiency in full-stack web development, focusing on component-based architecture, state management, and integration with modern technologies such as React for the frontend and Supabase for backend services and data management.
